# EduQR

Restoranlar ve kafeler için QR kodlu dijital menü platformu. Müşteriler QR kodu okutarak menüye anında ulaşır, işletmeler ise tek panelden menülerini, kampanyalarını ve müşteri geri bildirimlerini yönetir.

## Özellikler

- **QR menü** — fiziksel menü basmadan, anlık güncellenebilir dijital menü
- **Yönetim paneli** — kategori/ürün ekleme, sıralama, fiyat güncelleme
- **Müşteri etkileşimi** — çark çevirme (SpinWheel) ile kampanya, akıllı menü asistanı (anahtar kelime tabanlı filtreleme — alerjen, fiyat, kalori), geri bildirim toplama
- **Google yorum entegrasyonu** — müşterileri işletme yorumuna yönlendirme
- **PDF menü ve otomatik yazdırma** desteği
- **Abonelik ve ödeme yönetimi** — PayTR entegrasyonu ile restoran aboneliklerinin faturalandırılması
- **Süper admin paneli** — birden fazla restoranı tek yerden yönetme, fatura takibi

## Teknolojiler

Next.js (App Router) · TypeScript · Prisma + PostgreSQL · Clerk (kimlik doğrulama) · PayTR (ödeme) · Tailwind CSS

## Durum

Aktif geliştirilen bir SaaS ürünü, gerçek işletme müşterileriyle kullanımda.
